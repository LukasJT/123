# SEO and revenue measurement

Before deployment, record Search Console clicks, impressions, CTR, average position, indexed canonical pages, and representative URL inspection results by page type. Record analytics sessions, title-to-related-title clicks, guide-to-title clicks, return visits, page RPM, session revenue, ad viewability, and Core Web Vitals where access exists.

Compare each batch at roughly 2, 4, and 8 weeks using a 28-day baseline where possible. Separate branded and non-branded queries and account for seasonality. CPM, page RPM, and revenue per session answer different questions and must remain separate. Do not send raw search queries to analytics.

Expand a cluster when it earns relevant impressions and useful visits. Improve titles and snippets when impressions are healthy but CTR underperforms at comparable positions. Consolidate weak overlapping pages rather than increasing page count indefinitely. Lack of Search Console or revenue access must be reported, not replaced with invented estimates.
